# 🍁 덱 오브 메이플 (Deck of Maple)

> **"사서 위즈의 실수로 뒤섞인 과거의 기록! 팬텀을 동경하는 카드를 든 소년이 되어 엉켜버린 메이플 월드의 역사를 정화하라!"**

본 프로젝트는 **넥슨 메월드 아카데미 1기** 및 **<2026년 AI·가상융합(XR) 서비스 개발자 경진대회>** 출품작인 전략 덱 빌딩 로그라이크 게임 **[덱 오브 메이플]**입니다.

아래 메뉴를 클릭하시면 `Deck Of Maple` 폴더 내의 **[게임 기획.md] 문서 안의 해당 위치로 바로 이동**합니다.
